# セキュリティポリシー

🌐 [English](../../SECURITY.md) · [Français](SECURITY.fr.md) · **日本語**

## サポート対象バージョン

Kintaiは現在`1.0.0`未満のプレリリース段階であり、長期サポートブランチはまだ存在しません。
セキュリティ修正が提供されるのは `main` ブランチの最新コミットのみです。

| バージョン | サポート状況 |
|---------|-----------|
| `main`（最新） | ✅ |
| それ以前のバージョン | ❌ |

## 脆弱性の報告

**セキュリティ上の脆弱性については、公開issueを作成しないでください。**

GitHubの非公開脆弱性報告機能をご利用ください：
👉 [脆弱性を報告する](https://github.com/AudricSan/Kintai/security/advisories/new)

報告には以下を含めてください：
- 脆弱性の説明
- 再現手順
- 想定される影響
- 修正案（任意）

72時間以内に返信いたします。問題が確認され、修正版がリリースされた後、報告者への謝辞とともに脆弱性を公表します（匿名を希望される場合はその旨をお知らせください）。
