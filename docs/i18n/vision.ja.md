# プロダクトビジョン：Kintai

🌐 [English](../vision.md) · [Français](vision.fr.md) · **日本語**

## 🎯 ミッション
Kintaiのミッションは、中小規模の小売業・飲食業を、旧態依然としたシフト管理の煩わしさから解放することです。私たちは「紙に印刷されたExcelシート」と、高度なERP（統合基幹業務システム）との間に橋を架け、シンプルでありながら強力なソリューションを提供します。

## 🌟 「ソブリンSaaS」という哲学
データをブラックボックスに囲い込む従来型のSaaSプラットフォームとは異なり、Kintaiは**データ主権**を信条としています。私たちの顧客は単なる「テーブルの中の1行」ではなく、自らのデジタルインフラの所有者です。
- **物理的分離：** すべての顧客（オーナー）が、自身専用の分離されたデータベースを持ちます。
- **退出の自由：** 顧客は、私たちのホスティング型SaaSから自社ホスティングのインフラへ、データを一切失うことなく数分で移行できます。
- **プライバシー・バイ・デザイン：** セキュリティは後付けの発想ではなく、分離はデプロイモデルそのものに組み込まれています。

## 📍 ターゲット業種
Kintaiは、特定の国や地域ではなく、シフト制で複数拠点のチームを運用する中小企業全般を対象とします。
1. **中核：小売業・飲食業。** 「紙に印刷されたExcelシート」を象徴する店舗・レストラン・カフェ。
2. **拡大領域：その他のシフト制・複数拠点業種。** クリニックなどの医療施設、地域密着型サービス業、そして複数拠点で時給制スタッフを調整するあらゆる中小企業。

## 🚀 戦略的な柱
- **軽量なコア：** 安価なVPSからマネージドコンテナまで、あらゆる環境で動作する高速なPHPネイティブのコア。
- **設計はモジュール式、デフォルトはオープン：** メッセージングや日報、そして今後追加されるAI支援スケジューリングなどの高度な機能は、コアを肥大化させることなくフィーチャーフラグ付きバンドルとして提供されます — ただし、いずれのバンドルもこのリポジトリ内でAGPL-3.0として公開され、自由に自社ホスティングできます。
- **信頼に基づく成長：** オープンソースとしての透明性によって顧客を獲得し、マネージドSaaSオーケストレーションの利便性と信頼性によって顧客を維持する — アクセスできないコードによってではありません。

## 🌈 未来へ
Kintaiは「現場チーム管理のオープンスタンダード」となることを目指しています — 誰もがインストールできるが、誰もが私たちの最適化されたマネージドクラウド上で使うことを好む、そんな標準的なプラットフォームです。
